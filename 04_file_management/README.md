# Create files
```bash
touch filename.txt
touch filename1.txt filename2.txt # create more
```
# Create directories
```bash
mkdir dirname # creates a directory
```
# Remove files
```bash
rm filename.txt # removes a text file
rm -r # removes directory and its contents
```
# Move files
```bash
mv filename.txt newlocation/ # moves filename.txt to newlocation/
mv filename.txt filename2.txt # changes name
```
